# ⚡ HostelHub: The Neo-Brutalist Campus Marketplace

> **HostelHub** is a high-contrast, zero-noise, zero-brokerage campus marketplace built exclusively for Pondicherry University students (Kalapet, 605014). It eliminates the chaos of university WhatsApp groups by providing secure student authentication and localized peer-to-peer trading.

---

## 🎨 Design Aesthetic: Strict Neo-Brutalism
Inspired by modern brutalist design patterns, HostelHub features:
* **Bold 4px solid black borders** and hard offset drop shadows.
* **High-contrast vibrant palettes** (Electric cyan, hot pink, vibrant yellow) mixed with clean off-white backdrops (`#f4f4f0`).
* **Fluid Framer Motion micro-interactions** and smooth animated marquees.

---

## 🚀 Key Features
* **🔒 Verified Student Auth:** Secure login and signup flows mapped for university credentials.
* **📦 Localized Campus Listings:** Trade textbooks, lab kits, cycles, and electronics directly across campus blocks (e.g., Birsa Munda, Tagore, Sarojini Naidu, and Kasturba Gandhi hostels).
* **💬 Instant Student-to-Student Chats:** Direct interface to coordinate meetups safely on campus.
* **👤 Dynamic Profile Hub:** Manage active listings, track items marked as "Sold" or "Available", and view verified student credentials.

---

## 🛠️ Tech Stack
* **Frontend:** Next.js (App Router), React, TypeScript
* **Styling & Animation:** Tailwind CSS, Framer Motion
* **Backend & Database:** Supabase (Auth & PostgreSQL database)
* **Notifications:** Sonner toasts
